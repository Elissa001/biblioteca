# Breve descrição do roeto
Este projeto é um sistema de biblioteca feito em Python. Ele serve para cadastrar e organizar livros, além de permitir fazer empréstimos, devoluções, buscas e ordenar os livros.
# Como executar

# Principais funcionalidades
O programa permite cadastrar livros com título, autor, código e ano. Ele também lista os livros, busca um livro pelo título, empresta e devolve livros e ordena os livros por título, autor ou ano.
Os livros ficam salvos no arquivo livros.csv, então quando o programa é aberto novamente os livros cadastrados continuam salvos.
# Requisitos técnicos
No projeto foram usados if, elif e else para o menu, while para manter o programa funcionando até escolher a opção de sair, funções com parâmetros e retorno, lista de dicionários para guardar os livros e arquivo CSV para salvar e carregar os dados. E também foi usada a ordenação dos livros por título, autor e ano.
