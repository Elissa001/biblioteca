# Breve descrição do projeto
Este projeto é um sistema de biblioteca feito em Python. Ele serve para cadastrar e organizar livros, além de permitir fazer empréstimos, devoluções, buscas e ordenar os livros.

# Como executar
Para executar o programa abra o arquivo main.py, depois clique no botão de executar no canto superior direito (ou abrir um novo terminal e digitar o comando "python main.py" para rodar o código).
Ápos iniciar, irá aparecer o menu para escolher o que deseja fazer, seja cadastrar um livro, emprestar, etc.
Depois de escrever uma opção, lembrar sempre de clicar no enter.
E assim que terminar, escolha a opção 7 do menu para encerrar o programa.

# Principais funcionalidades
O programa permite cadastrar livros com título, autor, código e ano. Ele também lista os livros, busca um livro pelo título, empresta e devolve livros e ordena os livros por título, autor ou ano.
Os livros ficam salvos no arquivo livros.csv, então quando o programa é aberto novamente os livros cadastrados continuam salvos.

# Requisitos técnicos
if, elif e else no menu 
while para manter o menu funcionando até escolher a opção de sair 
Funções com parâmetros e retorno
Lista de dicionários para armazenar os livros 
Leitura e escrita no arquivo livros.csv 
Ordenação dos livros por título, autor e ano
